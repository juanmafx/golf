# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Pre-1.0 code from 2018 | No |

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository if it is available. Otherwise, open an issue that asks for a private contact and leave out any exploit details.

Include the affected version, the impact and the steps needed to reproduce the issue.

## Security controls

Controls and known limitations are documented in [docs/SECURITY_AUDIT.md](docs/SECURITY_AUDIT.md).
